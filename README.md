# 🌱 Plataforma Institucional — Associação de Camponeses Henda (ACH)

> **"Unidos pela Terra, Produzimos o Futuro"**

Plataforma digital completa (Web + Mobile) para a gestão de membros, emissão/validação de credenciais digitais via QR Code e fortalecimento da presença institucional da **Associação de Camponeses Henda (ACH)**, sediada no município de **Calumbo, província de Icolo e Bengo — Angola**.

---

## 📋 Sobre o Projeto

A ACH é uma organização de base comunitária que representa camponeses dedicados à agricultura familiar, segurança alimentar e desenvolvimento comunitário. Esta plataforma foi concebida para modernizar a gestão da associação e facilitar o trabalho dos fiscais em campo.

### ✨ Funcionalidades Principais

- **Site Institucional Público** com Missão, Visão, Valores, Pilares e Notícias.
- **Portal de Gestão** com autenticação para Administradores e Fiscais.
- **Registo de Membros** com atribuição automática de número sequencial.
- **Emissão de Credenciais Digitais** com QR Code gerado dinamicamente.
- **Scanner de Validação** (protótipo) para verificação em tempo real.
- **Botão Flutuante de WhatsApp** para contacto direto com a associação.
- **Design Premium** responsivo (Mobile-First) com identidade visual institucional.
